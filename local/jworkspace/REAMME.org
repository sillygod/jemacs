* Persistence

Save file: =(locate-user-emacs-file "jworkspace")= (versioned plist),
which follows =user-emacs-directory= (in this config,
=emacs-home/jworkspace=).  Override with =jworkspace-save-file=.
An older =.jworkspace/save-workspace= under the same directory is
still read if the new file is missing.
=M-x jworkspace-save-workspace= / =M-x jworkspace-load-workspace=.
=jworkspace-startup= (on =window-setup-hook=) loads that file if it
exists, otherwise creates =main=.

Load does *not* visit files.  Identities stay in =saved-ids= until you
switch to that workspace (or list its buffers).  =find-file-hook= is
inhibited while those files are opened so they are not stolen by the
workspace that happens to be current.

After load, the frame's =current-workspace= is rebound to the new
struct of the same name so a subsequent save does not write into a
stale object.

Maximize is undone before switch/save so the stored layout is the
real split, not the single window.
