#+TITLE: ghostel-cmd

Per-project Ghostel command bookmarks with a GhostHerd-style overlay.

* Status

| Item     | Value                                            |
|----------+--------------------------------------------------|
| Package  | =local/ghostel-cmd/= (straight =:local-repo=)     |
| Files    | =ghostel-cmd.el= · =ghostel-cmd-tests.el=         |
| Wired in | =jemacs-project= · =SPC p c= · Ghostel =C-c c=    |

* Overlay

Posframe when available, side window otherwise.

| Key        | Action                                      |
|------------+---------------------------------------------|
| =j= / =k=  | Move                                        |
| =RET=      | Paste (fill ={{vars}}= on the footer first) |
| =C-RET=    | Paste and press Enter                       |
| =/=        | Live-narrow (flex, whitespace is AND)       |
|            | every printable key types; =C-n= =C-p= move |
| =a= =e= =d=| Add / edit / delete; edit keeps the place   |
|            | a name already taken asks before replacing  |
| =M-j= =M-k=| Move the command down / up, saved           |
|            | (=M-<down>= =M-<up>= too)                   |
| =C-y=      | Yank into the filter or fill input; one     |
|            | line, newlines become spaces                |
| =q= / Esc  | Quit; during fill, cancel fill              |

Placeholders, the built-ins taken from where you opened the overlay:

| Placeholder                  | Value                                      |
|------------------------------+--------------------------------------------|
| ={{file}}= / ={{file-abs}}=  | caller's file, relative to the root / absolute |
| ={{dir}}=                    | caller's directory relative to the root (=.=) |
| ={{line}}=                   | caller's line                              |
| ={{symbol}}=                 | symbol at point in the caller              |
| ={{root}}= ={{project-name}}= ={{branch}}= | the project                  |
| ={{name}}= / ={{name:default}}= | asked on the footer                     |

The value you last filled for a ={{name}}= (per project and command,
for this Emacs session) is offered before its =:default=.  Built-ins
are always taken fresh.

A name starts with a letter or
underscore; any other ={{...}}= stays literal, so docker's
={{.State.Status}}= and helm's ={{ .Values.x }}= paste as written (Go's
={{end}}= still reads as a variable).  Filling happens on the overlay
footer, not a chain of minibuffers.  =RET= never sends Enter unless
you use =C-RET=.

The overlay is the only menu.  Open a terminal with =SPC '=, replay
the last command with =SPC TAB=, send a region with =SPC x s=.

#+begin_src sh
  emacs --batch --init-directory=~/.emacs.d/emacs-home/ \
        -L ~/.emacs.d/local/ghostel-cmd \
        -l ghostel-cmd.el -l ghostel-cmd-tests.el \
        -f ert-run-tests-batch-and-exit
#+end_src
