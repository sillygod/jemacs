#+TITLE: ghostel-cmd

Per-project Ghostel command bookmarks with a GhostHerd-style overlay.

* Status

| Item     | Value                                          |
|----------+------------------------------------------------|
| Package  | =local/ghostel-cmd/= (straight =:local-repo=)  |
| Files    | =ghostel-cmd.el= · =ghostel-cmd-tests.el=      |
| Wired in | =jemacs-project= · =SPC p c= · Ghostel =C-c c= |

* Overlay

Posframe when available, side window otherwise.  Selecting another
window (a click, say) closes the posframe and leaves focus there; the
minibuffer does not count.

| Key         | Action                                            |
|-------------+---------------------------------------------------|
| =j= / =k=   | Move                                              |
| =RET=       | Paste (fill ={{vars}}= on the footer first)       |
| =C-RET=     | Paste and press Enter                             |
| =/=         | Live-narrow (flex, whitespace is AND); every      |
|             | printable key types, =C-n= / =C-p= move           |
| =a= =A=     | Add to the project / to the global commands       |
| =e= =d=     | Edit / delete, in the command's own list; edit    |
|             | keeps the place, a name already taken asks first  |
| =m=         | Move the command to the global list, or back; a   |
|             | task is copied into the project's list            |
| =M-j= =M-k= | Move the command down / up, saved (=M-<down>= /   |
|             | =M-<up>= too)                                     |
| =C-n= =C-p= | While filling a variable with choices: the next / |
|             | previous choice (=<down>= / =<up>= too)           |
| =C-y=       | Yank into the filter or fill input, as one line:  |
|             | newlines become spaces                            |
| =C-\=       | Type the filter or fill input in the minibuffer,  |
|             | =default-input-method= on                         |
| =q= / Esc   | Quit; during fill, cancel fill                    |

Any character types into the filter and the fill input, and so does
text a system input method (Squirrel) commits.  An Emacs input method
(rime, quail) cannot compose in the read-only overlay, and evil turns
it off in normal state, so =C-\= edits the input in the minibuffer with
it on; the list follows as you type and =C-g= keeps the old text.

The preview under the list wraps a long command onto at most
=ghostel-cmd-preview-max-lines= (3) lines and cuts the rest with =…=,
so a huge command never pushes the list away.

* Global commands

=A= adds a command every project shares.  The list shows the
project's commands, then the global ones, and a From column tags each
row (=proj=, =global=) once there is more than the project's own.  A
name is unique within its list, so a project command and a global one
may share it and both show.  =m= moves the command at point to the
other list; =e=, =d= and =M-j= / =M-k= stay in the list it is in.

* Tasks

After the bookmarks the overlay lists the tasks it finds in the
project root, tagged by where they come from.  The files are only
parsed, never run, and parsed again once one of them changes.

| File                    | Tasks           | Pasted as         |
|-------------------------+-----------------+-------------------|
| =package.json=          | ="scripts"=     | =RUNNER run NAME= |
| =GNUmakefile=,          | literal targets | =make TARGET=     |
| =makefile=, =Makefile=  |                 |                   |
| =justfile=, =Justfile=, | public recipes  | =just RECIPE=     |
| =.justfile=             |                 |                   |

- The runner, and the tag, is the one the lockfile names:
  =pnpm-lock.yaml= → pnpm, =yarn.lock= → yarn, =bun.lock= or
  =bun.lockb= → bun; without one, the =packageManager= field's, else
  npm.  The script itself is the description.
- Make reads the first of its three files, as make does.  Left out:
  assignments, =.PHONY= and every other target starting with =.=,
  pattern rules, targets built from a variable, target-specific
  variables and =define= bodies.  =## text= after a rule describes it.
  Included makefiles are not followed.
- Just recipes marked =[private]= or starting with =_= are left out,
  as =just --list= leaves them out; the comment right above a recipe,
  or its =[doc(...)]=, describes it.

Tasks are read-only: =RET= / =C-RET= paste them like any command, and
=m= copies the one at point into the project's list to edit there.  A
=package.json= or Makefile that does not parse lists nothing, with a
message.  =ghostel-cmd-discover= turns discovery off (=nil=) or keeps
some sources (='(npm just)=).

* Placeholders

Built-ins are taken from where you opened the overlay:

| Placeholder                     | Value                                          |
|---------------------------------+------------------------------------------------|
| ={{file}}= / ={{file-abs}}=     | caller's file, relative to the root / absolute |
| ={{dir}}=                       | caller's directory, relative to the root (=.=) |
| ={{line}}=                      | caller's line                                  |
| ={{symbol}}=                    | symbol at point in the caller                  |
| ={{root}}= ={{project-name}}=   | the project                                    |
| ={{branch}}=                    | the git branch                                 |
| ={{name}}= / ={{name:default}}= | asked on the footer                            |

={{name:a|b|c}}= offers choices, the first one the default.  The
footer lists them with the current one in brackets; =C-n= / =C-p= (or
the arrows) pick another, and typing, =C-y= or =DEL= replace the picked
one with your own text.  A default meant to hold a literal =|= cannot:
it always reads as choices.

The value you last filled for a ={{name}}= (per project and command,
for this Emacs session; a global command's per project too) is
offered before its =:default=, and starts the next fill whether it
was a choice or your own text.  Built-ins are always taken fresh.

A name starts with a letter or underscore; any other ={{...}}= stays
literal, so docker's ={{.State.Status}}= and helm's ={{ .Values.x }}=
paste as written.  There is no escape, so Go's ={{end}}= still reads
as a variable.

Filling happens on the overlay footer, not a chain of minibuffers.
=RET= never sends Enter unless you use =C-RET=.

* Save file

Commands live in =ghostel-cmd-save-file=, keyed by project root; the
global ones sit under the =:global= key.  =o= opens it.  An edit made
there, or by another Emacs, is read on the next open or redraw, and a
save applies its change to the file as it is on disk.  A file that
does not parse is left alone: the overlay keeps what it had and
refuses to save until the file reads again.

The overlay is the only menu.  Open a terminal with =SPC '=, replay
the last command with =SPC TAB=, send a region with =SPC x s=.

#+begin_src sh
  emacs --batch --init-directory=~/.emacs.d/emacs-home/ \
        -L ~/.emacs.d/local/ghostel-cmd \
        -l ghostel-cmd.el -l ghostel-cmd-tests.el \
        -f ert-run-tests-batch-and-exit
#+end_src
